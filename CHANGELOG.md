# Changelog

## v1.0.0

First versioned release of the existing downloader.

- Download Albion Online item and spell icons by curated names, aliases or spell IDs.
- Use command, silent interactive or batch-file modes, including terminal selection of spell variants.
- Install or update on macOS/Linux and Windows using matching runtime and catalogue files.
- Add `download --version` and install from version-pinned GitHub release assets.

Local verification results and platform limitations are recorded in `RELEASES.md`.
