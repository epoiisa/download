# Changelog

## v1.1.0 (unreleased)

- Add Firewing Drake Egg and Tame Firewing Drake to the catalogue alongside the existing Firewing Drake mount. All three accept tier 8, enchantment 0 and normal quality; tier may be omitted.
- Accept enchantment 0 for Waystone (Large Group) at tiers 6–8 and use it when enchantment is omitted, matching the other dungeon-map families. Existing explicit levels 1–4 are unchanged. Successful zero-enchantment rendering still depends on Albion's Render Service.

## v1.0.0

First versioned release of the existing downloader.

- Download Albion Online item and spell icons by curated names, aliases or spell IDs.
- Use command, silent interactive or batch-file modes, including terminal selection of spell variants.
- Install or update on macOS/Linux and Windows using matching runtime and catalogue files.
- Add `download --version` and install from version-pinned GitHub release assets.

Local verification results and platform limitations are recorded in `RELEASES.md`.
